# ☀️ Dashboard de Energia Solar Residencial

Este projeto foi desenvolvido para a disciplina **UPX-III - Usina de Projetos Experimentais III**, no curso de **Análise e Desenvolvimento de Sistemas**. Ele oferece uma solução interativa e acessível para **monitoramento da geração e consumo de energia solar** em residências.

---

## 📌 Descrição

O sistema consiste em um **dashboard desenvolvido com Python, Streamlit e Plotly**, focado em apresentar, de forma visual e compreensível, os dados de eficiência energética provenientes de sistemas fotovoltaicos residenciais.

### 🔗 Acesso Rápido

Você pode acessar o dashboard diretamente por este link:  
👉 [Abrir Dashboard de Energia Solar](https://dashboard-energia-solar-ntvrfhsa2nil39lyctvvz6.streamlit.app/)

## 🚀 Como Executar Localmente

### 1. Clone o repositório

git clone https://github.com/seu-usuario/nome-do-repositorio.git
cd nome-do-repositorio

2. Instale os pacotes Python necessários

pip install -r requirements.txt

3. Rode o dashboard localmente

streamlit run dashboard_energia_solar.py
Acesse http://localhost:8501 após iniciar o servidor.
